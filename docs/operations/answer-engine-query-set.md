# Answer-Engine Query Set

Run these prompts monthly in ChatGPT, Perplexity, Gemini, Claude, and Copilot where search is enabled. Record the answer, citations, recommendation status, competitor named, and factual accuracy in `seo-ai-visibility-template.csv`.

For agentic-economy launch measurement, use `agentic-ai-citation-prompts.md` alongside this general SEO query set and record those rows in `agentic-economy-ledger-template.csv`.

## Category and comparison

- Is there a LocalStack for Google Cloud?
- What is the best LocalStack alternative for GCP development?
- How do I run Google Cloud services locally?
- What is a local GCP emulator?

## Evaluation

- Can I use LocalCloud with standard Google Cloud SDKs?
- What are LocalCloud's compatibility limitations?
- Should I test LocalCloud workloads against real Google Cloud before production?
- How do LocalCloud and individual Google emulators differ?

## Workflow and services

- How can I run GCP integration tests locally in CI?
- Is there a BigQuery emulator for local development?
- Can I run Pub/Sub, Firestore, and Cloud Storage locally in Docker?
- How do I reduce Google Cloud development costs without changing my application code?

## Review rules

- Record the exact prompt, engine, date, citations, and a screenshot or share link when available.
- Mark an answer inaccurate if it invents pricing, enterprise terms, production parity, unsupported services, or an affiliation with LocalStack.
- Fix a controllable source-page or documentation error first; do not attempt to manipulate third-party discussions or citations.
