# Privacy Policy

**Last updated: May 2025**

## Website (local.cloud)

The LocalCloud website is a static site hosted on GitHub Pages. We do not:

- Collect personal information through forms or accounts
- Use cookies for tracking or advertising
- Share data with third parties

We use **PostHog** for anonymous product analytics (page views, feature usage). PostHog processes IP addresses to determine country-level geography but we do not store or associate this with individual identities.

## LocalCloud Software

The LocalCloud Docker image runs entirely on your machine. It does not:

- Send telemetry or usage data to any server
- Phone home or make outbound connections except those you configure
- Collect or transmit any of your data
