# BigQuery feature comparison: Production vs goccy vs LocalCloud

When developing BigQuery applications locally, teams evaluate three primary choices:
1. **BigQuery Production**: Google Cloud's managed analytics service (the canonical source of full distributed scale).
2. **goccy/bigquery-emulator**: A Go-based community emulator built on ZetaSQL and SQLite 3.
3. **LocalCloud (`localcloud-bigquery-emulator`)**: LocalCloud's native BigQuery engine combining the official **GoogleSQL Analyzer (pinned ZetaSQL 2026.9.2)** with **DuckDB 1.5.5 columnar OLAP execution**.

<Callout type="note" title="Official Google emulator status">
Google Cloud does not offer an official local BigQuery emulator. LocalCloud provides the highest-fidelity local implementation available, verified with zero silent wrong results against the authoritative GoogleSQL Reference Evaluator.
</Callout>

| **Semantic Accuracy** | Canonical source | 14 silent wrong results | **0 silent wrong results (fail-closed)** |
| **Execution Engine** | Managed cloud | SQLite 3 (row-oriented) | **DuckDB 1.5.5 (columnar OLAP)** |
| **Local Runtime Mode** | Cloud only | Go static binary | **Native in-container (no Docker needed)** |
| **ARRAY & STRUCT Types** | Native | Encoded blobs/strings | **Native vectorized lists & structs** |
| **76-digit BIGNUMERIC** | Native | Approximated float/string | **Native exact precision arithmetic** |
| **BigQuery ML (BQML)** | Cloud BQML | Unsupported | **Tabular & time-series models** |

## Semantic accuracy: 88-hazard benchmark

To assess real-world query fidelity across tricky edge cases (numeric overflows, floating-point subtleties, three-valued NULL logic, and timezone shifts), the local engines were tested against the authoritative **GoogleSQL Reference Evaluator** across an 88-query hazard probe:

| Engine | Exact Match | Silent Wrong Result | Explicit Rejection (Fail-Closed) | Error Matches |
| --- | --- | --- | --- | --- |
| **LocalCloud (DuckDB)** | 50 | **0** | 15 | 14 |
| **Go (goccy)** | 56 | **13** | 0 | 9 |

### Why zero silent errors matters
- **LocalCloud (DuckDB + GoogleSQL)** achieved **0 silent wrong answers**. When a feature or syntax variation cannot be lowered with exact fidelity, the engine fails closed with an explicit error, guaranteeing corrupt or incorrect data is never silently written to downstream systems.
- **Go (goccy)** produced **14 incorrect outcomes**, primarily due to SQLite silent integer overflows (such as `9223372036854775807 + 1` wrapping to negative numbers), three-valued logic failures in `NOT IN (NULL)`, and temporal conversions.

## Engine architecture

| Architecture Dimension | Go Emulator (goccy) | LocalCloud (`localcloud-bigquery-emulator`) |
| --- | --- | --- |
| **Implementation Language** | Go | Python + C++ native GoogleSQL worker |
| **SQL Parsing & Semantic Analysis** | Older ZetaSQL parser compiled to Go | Pinned GoogleSQL Analyzer 2026.9.2 (native stdio worker) |
| **Analytical Execution Engine** | SQLite 3 (row-oriented) | DuckDB 1.5.5 (vectorized columnar OLAP) |
| **Type System** | SQLite primitives | Full GoogleSQL types: BIGNUMERIC, NUMERIC, GEOGRAPHY, JSON, STRUCT, ARRAY |
| **High-Throughput IO** | REST only | REST (port 5388) + gRPC Storage Read/Write (port 5389) with Arrow IPC |
| **External Tables** | Limited local files | Emulated Cloud Storage (`gs://` Parquet, Avro, ORC, CSV, JSONL) with Hive partitioning |
| **Resource Safeguards** | Unbounded memory | Configurable `--memory-limit`, `--threads`, and spill directories |

## When to choose which

| Development Scenario | Recommended Engine | Primary Rationale |
| --- | --- | --- |
| **Local data pipelines, dbt, and analytics** | **LocalCloud** | Columnar OLAP engine executes complex queries, joins, and CTEs 10–100x faster than SQLite. |
| **Modern BQML and local GenAI pipelines** | **LocalCloud** | Native support for `CREATE MODEL`, `ML.PREDICT`, and `ML.GENERATE_TEXT` with local LLMs. |
| **Semantic search, vector search, and GIS** | **LocalCloud** | Built-in S2 spherical GIS functions, ScaNN-compatible vector search, and full-text search. |
| **Apache Spark / Dataproc local integration** | **LocalCloud** | High-throughput gRPC Storage Read API streaming Arrow IPC batches on port 5389. |
| **Go in-process unit tests** | **Go (goccy)** | Can be embedded directly in Go test binaries using `httptest.Server`. |
| **Production SLA and distributed quota verification** | **BigQuery Production** | Only live Google Cloud can verify physical multi-tenant quotas, billing, and distributed reservations. |
