# Bigtable emulator feature reference

LocalCloud runs a separately maintained Bigtable emulator for row and administration APIs. The current Docker build pins a source commit.

<Callout type="warning" title="Test the paths you need">
The runtime contract records each operation's concrete boundaries. The `latest` image tag is mutable; confirm the packaged dependency version and test the exact row, administration, and recovery paths you need.
</Callout>

## Connection and persistence

| Surface | Canonical value | Boundary |
| --- | --- | --- |
| Primary API | gRPC on `localhost:5385` | Use `BIGTABLE_EMULATOR_HOST` from `localcloud env` for actual mapped ports. |
| Backing store | PostgreSQL under the mounted LocalCloud volume | A standalone dependency's SQLite configuration is not the LocalCloud default. |
| Console SQL | LocalCloud SQL-to-row-API translator | Separate from native GoogleSQL `PrepareQuery` / `ExecuteQuery` and session protocols. |

## Runtime and recovery limits

LocalCloud uses PostgreSQL-backed persistence. Test a restart against the mounted volume and compare exact row bytes. IAM is permissive, change streams use one partition, and local HLL++/multi-column view-key encodings differ from cloud representations.

## Verify backup and cleanup behavior

1. Write known row keys, families, qualifiers, timestamps, and values through the native client.
2. Create a data-bearing backup and restore it to a separate table. Read the restored cells and compare the bytes; metadata readback alone is insufficient.
3. List backups through the native administration API when using filters, ordering, or pagination. The REST path ignores those options.
4. Delete owned backups and clear resource deletion protection before deleting the instance or project. If cleanup fails, inspect the native API error and retained project record.

For row-filter tests, `Sink` preserves cells past subsequent filters and is invalid inside a `Condition`. Verify writes through the native API when the Console does not surface a rejection. Validate managed replication and production authorization in Google Cloud.
