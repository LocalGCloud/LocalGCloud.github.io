# Bigtable emulator feature reference

LocalCloud runs a separately maintained Bigtable emulator for row and administration APIs. The current Docker build pins a source commit. Historical cached-artifact observations do not establish support in the current assembled image.

<Callout type="warning" title="Operation and image qualification">
The runtime contract records each operation's concrete boundaries. The mutable LocalCloud image tag remains release-unverified. Confirm the packaged dependency identity and test the exact row, administration, and recovery paths you need.
</Callout>

## Connection and persistence

| Surface | Canonical value | Boundary |
| --- | --- | --- |
| Primary API | gRPC on `localhost:5385` | Use `BIGTABLE_EMULATOR_HOST` from `localcloud env` for actual mapped ports. |
| Backing store | PostgreSQL under the mounted LocalCloud volume | A standalone dependency's SQLite configuration is not the LocalCloud default. |
| Console SQL | LocalCloud SQL-to-row-API translator | Separate from native GoogleSQL `PrepareQuery` / `ExecuteQuery` and session protocols. |
