# Licensing reference

The governing **LocalCloud Public Preview License Agreement** is a proprietary license issued by **LocalCloud Inc.** The <a href={governingLicenseUrl}>complete license agreement</a> controls; this page summarizes the current terms.

<Callout type="info" title="Free public preview">
Individuals and organizations, including for-profit companies, may use LocalCloud free of charge for the permitted non-production workflows below. No payment method or license key is required.
</Callout>

## Permitted preview use

The Public Preview License covers:

- personal learning, education, teaching, academic research, experimentation, and personal projects;
- internal software development, debugging, testing, and quality assurance;
- ongoing internal CI and delivery automation;
- internal evaluation, proofs of concept, and internal pilots; and
- internal nonprofit development, testing, research, education, and mission-related work.

Employees and contractors may use LocalCloud on behalf of an organization for these workflows. The organization remains responsible for their compliance with the agreement.

## Uses outside the preview grant

The preview grant does not cover customer-facing or other production use, reselling LocalCloud, offering it as a hosted or managed service, redistribution, sublicensing, or modification. The complete agreement contains the controlling definitions and restrictions.

LocalCloud is a development and testing environment. Validate release behavior against real Google Cloud before deploying an application to production.

## Preview releases keep their terms

Each version first distributed under the Public Preview License remains available to its licensees under those terms. LocalCloud Inc. may offer later versions, support, services, or features under different terms, but those later terms do not retroactively replace the grant for a preview release already obtained under the agreement. Rights may still terminate for breach.

## Technical enforcement

| Runtime condition | Technical behavior | Legal boundary |
| --- | --- | --- |
| Current public-preview release | Starts without a license key and grants technical Pro access. | Use remains limited to the Public Preview License. |
| Development build | May disable enforcement and grant technical Pro access. | Development metadata does not expand the license grant. |
| Separately enforced build | Requires `LOCALCLOUD_API_KEY`; validation failure terminates startup. | A technically accepted key does not grant production, redistribution, or hosted-service rights. |
| Service `minTier` | Controls technical service availability when tier enforcement is active. | Community/Pro labels are access controls, not pricing plans. |

## License metadata conflicts

Some historical package and image metadata previously declared `Apache-2.0`, including a runtime OCI label. Those declarations conflict with the governing proprietary root license and must not be used to infer LocalCloud runtime permissions.

The LocalCloud runtime, including its <a href={`${productFacts.runtimeRepositoryUrl}/blob/main/docs/MCP_INTEGRATION.md`}>built-in MCP integration</a>, remains governed by the runtime repository license. Technical access through the canonical `/mcp` endpoint or the `localcloud mcp` stdio bridge does not create a separate grant.

## Before using LocalCloud

1. Read the <a href={governingLicenseUrl}>complete governing license</a> shipped with the release you plan to use.
2. Keep LocalCloud within the permitted non-production workflows.
3. Check the compatibility contract for the services and operations your workflow needs.
4. Validate authorized production behavior against real Google Cloud.
