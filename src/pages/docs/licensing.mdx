# Licensing

LocalCloud is **free for individual developers** for evaluation, personal projects, learning, and testing.

## What's Allowed

- **Personal projects** — building your own apps and side projects
- **Learning & evaluation** — trying LocalCloud, exploring Google Cloud APIs locally, following tutorials
- **Testing & experimentation** — non-commercial testing and prototyping
- **Academic research** — educational and research use

## What's Not Allowed

- **Commercial use** — any use by or for a commercial entity, including internal development workflows for commercial products
- **Production use** — running LocalCloud as part of a production system or serving production traffic
- **Redistribution** — bundling LocalCloud into a commercial product or service

<Callout type="warning" title="Need commercial use?">
If your team or organization needs a commercial license, contact <a href="mailto:licensing@localcloud.dev">licensing@localcloud.dev</a>.
</Callout>

## How It Works

LocalCloud includes a license-gate mechanism in the Docker image, but **enforcement is not active**. You can pull and run the image without any license key or registration. The gate infrastructure exists for future use but is currently disabled.

## Full License

The complete terms are in the [LICENSE](https://github.com/LocalStack-Google/localstack-google.github.io/blob/main/LICENSE) file in the project repository.

## Future Changes

The licensing model may evolve over time. If a paid commercial tier becomes available in the future, individual developer use will remain free. Any changes will be communicated through the project channels.
