# Licensing

LocalCloud is **free for developers**.

## Current Terms

The [LICENSE](https://github.com/LocalGCloud/LocalGCloud.github.io/blob/main/LICENSE) in the project repository is the governing source for LocalCloud terms.

## Runtime Boundary

LocalCloud is designed for local development, testing, CI, and demos. Validate against real Google Cloud before production deployment.

<Callout type="info" title="Keep the inner loop local">
Use LocalCloud to develop and test against local Google Cloud service behavior, then validate production-critical paths against real Google Cloud.
</Callout>
