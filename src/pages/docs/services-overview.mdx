# Services overview

The runtime registry contains {serviceRegistryCount} Google Cloud identities. The public catalog exposes {publishedServiceCount} guides: {availableServiceCount} available services and {comingSoonServiceCount} roadmap addition. Google Sheets remains an integration surface rather than a LocalCloud service.

A registry entry does **not** mean full Google Cloud parity or that a service is enabled in every assembled image. Read six separate fields:

1. **Registry default** — the service registry's default before container-environment overrides.
2. **Assembled default** — whether the reviewed container starts it by default and how well that default is qualified.
3. **Minimum tier** — community or Pro; this is a technical boundary, not a license grant.
4. **Evidence state** — verified, partial, release-unverified, unsupported, or unknown.
5. **Persistence** — service-data, metadata, volatile, or stateless, with a separate qualification.
6. **Operation limits** — the bounded workflows and known gaps.

## Categories

The catalog groups services by user goal—storage, databases, analytics, messaging/workflow, security, operations, and compute/runtime—but implementation boundaries differ inside every category. Some are external emulator processes, some are local facades, and some require Docker-socket or transparent-network opt-ins.

## How to use the catalog

- Load the actual running endpoints with `localcloud env`; the host CLI may remap ports.
- Check the service detail and operation evidence before writing a test.
- Treat release-unverified dependency services as requiring an identified source revision and assembled-image qualification.
- Keep the runtime loopback-bound and use fake local data.
- Remove emulator variables and validate production behavior against real Google Cloud before release.

Open the [service catalog](/services/) for all 26 public guides or [Compatibility](/compatibility/) for cross-service operation evidence. Google Sheets remains an integration surface and is not listed as a LocalCloud service.
