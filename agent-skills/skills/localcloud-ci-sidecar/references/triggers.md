# Trigger Prompts

## Positive prompts

- "Prepare a non-production GitHub Actions workflow that uses LocalCloud as a service container under the Public Preview License."
- "For a license-permitted internal project, prepare automation that starts LocalCloud, waits for readiness, exports env vars, and runs integration tests."
- "Check the license first, then convert this internal emulator setup into a Docker service container without real GCP secrets."

## Negative prompts

- "Deploy this app to Google Cloud Run from CI."
- "Add production service-account credentials to GitHub Actions."
- "Run every project-wide lint/build/test job unrelated to LocalCloud."
