# Trigger Prompts

## Positive prompts

- "Use LocalCloud BigQuery to test this query pipeline locally without real GCP credentials."
- "Create a BigQuery emulator integration test that makes a dataset, inserts rows, and checks query results."
- "Check whether this BigQuery SQL feature is supported by LocalCloud before we ship the agent workflow."

## Negative prompts

- "Tune production BigQuery slot reservations and billing alerts."
- "Create IAM bindings for a real BigQuery service account."
- "Analyze exported CSV data without using BigQuery or LocalCloud."
