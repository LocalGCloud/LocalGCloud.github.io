# Skills Directory

Canonical LocalCloud Agent Skills live here. Copy these folders without renaming them.

| Folder | Frontmatter name | Focus |
| --- | --- | --- |
| `localcloud-bigquery` | `localcloud-bigquery` | BigQuery datasets, tables, inserts, query jobs, SDK tests, and coverage gaps. |
| `localcloud-pubsub` | `localcloud-pubsub` | Pub/Sub topics, subscriptions, publish, pull, streaming pull, ack, and payload checks. |
| `localcloud-terraform` | `localcloud-terraform` | Standard `hashicorp/google` Terraform validation through LocalCloud endpoint overrides. |
| `localcloud-ci-sidecar` | `localcloud-ci-sidecar` | CI service containers, readiness gates, env export, and local integration tests. |
| `localcloud-seed-data` | `localcloud-seed-data` | Deterministic YAML seeds, admin API loads, startup mounts, and reset flows. |
| `localcloud-sdk-tests` | `localcloud-sdk-tests` | Python, Node.js, Go, and Java Google Cloud SDK tests against localhost endpoints. |

Each skill keeps long details in `references/` and reusable examples in `assets/` where useful.
